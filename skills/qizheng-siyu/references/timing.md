# 行限与应期

读盘主线是原局、宫限与度限、流年，再按问题下推月日时。计算器以本命和目标时间提供各层盘面证据，喜用及象意依此流程判读。

## 大限

1. **先定原局。** 明确命元及喜、用、忌，参考尽三和三度的证据。记录哪些未发的组合与用户问的主题有关。本命组合的强弱、所在与所掌之宫，决定被引动时如何取象。
2. **宫限论宫。** 定出是哪一地支和人事宫。按本宫、对宫、两三合查本命星，说明星所守、所掌和在原局的角色。空宫继续查对宫、三合和宫主。以此定位阶段环境和宫上组合。
3. **度限论度。** 先定当下宿度主，取其同曜四宿查本命吊星。相同宿主的各宿可能落在不同地支宫，故保留宫限判断。度限优先定主要倾向，宫限补出场景和同向或逆向条件。限度主星所飞之宫宿可作取象补证。
4. **分别看命与限。** 一方面限度与宫度吊星改变命局喜忌的发挥，另一方面以限度为太极，看其本身有无生助、受克或余奴相犯。例如木度受金为克限，木度遇炁为犯限。克限的星仍能是本命喜星，因而事情可有收获，同时伴随波折。喜星犯限与强忌直接克限应分别标注。
5. **跨界给区段。** 同年可能过宫或换宿，依所问日期列所涉区段。查看 JSON 的宫限边界和宿度区段。年内代表点可帮助浏览。遇到具体事件日期或临界情况再查该时刻和前后区段。

**核实限上星。** 论度限用同曜宿吊星。核实星的宿曜与当前限度是否相应，单有地支宫上的相见留给宫限论。若以后由太岁填吊或顶星再引动，届时再纳入该层。判断限受损先列直接克限、余奴犯限及限上关键星受伤。单见泄气可作旁证。主限和限上星同时受伤后，还要查哪些喜曜或制化仍在。

## 流年

1. **顶星优先。** 按排盘确定本命星的顶星接触及实际限度，留意同时顶到的星和边界。每颗顶星先分别作用于原局的命、用、忌，再分别作用于限度及限上星。顶到命主星可先取其所掌人事和本人感受，顶到自己的余曜仍按尽三定的余奴作用。全年资料和精确到某时的资料各为其适用范围。
2. **太岁填冲。** 在流年太岁所在的本命地支宫取本宫、对宫、两三合。列出具体原局星、流四余和位置，分别核实它们如何动命与动限。流年以罗计、紫炁、月孛为重点，当时的流七政可供补证。看年化曜时也落到具体星上。
3. **取并象。** 某星同时见于度限、顶星、太岁填冲或流四余，又与原局结构呼应时，优先说明证据重叠的议题。顶星与太岁填星各自作用于命和限，两组之间按重复取并象。流年引出限上信息，方向从流年到限、到命。先说明直接作用，之后再综合同层耦合。
4. **同星异年比较。** 遇相同顶星而结果不同，按当年宫度、同曜吊星、原局护用、太岁填冲、同现流星逐一对照。例如同顶金，木度要看受克，火度还要看是否原有水孛伤限及有无救应。盘面达不到条件时收窄判断。

**从年缩小到月。** 先找原局已有的主题及该年起作用的星。若这一星只在上半年或下半年的宫度段有效，先按区段取舍，再列哪些月限、月将或流星重复引动同一曜。原流同曜取并象。只有流月也支持时，再把解释收窄到该月。流日、流时的查宫按人事宫取象。

可对照相邻节气月的月限、月将。若前一月引动对外接洽，后一月重心转向官禄，要说明前后分别查邀约安排与职责落定的哪一环。以交节划分时间，当日快行星或顶星按当时盘使用。

## 小限、流月、流日、流时

- **小限起月限。** 取该年小限的地支宫，从该宫起本命节气月支，顺数月份、沿地支逆走一宫，数到所问节气月。月限看本命宫的三方四正以及象落何处。例如小限午、生月亥、所问午月，算得月限亥。
- **月将作为并象。** 寅卯辰巳午未申酉戌亥子丑月依次对应子亥戌酉申未午巳辰卯寅丑宫。月限为主，月将和月限所引星曜重复时，说明重复为何增强该主题。
- **流日。** 取所问日的日支宫及当时月亮的地支宫，两者都看三方四正。比对实际流星与流月、流年是否同象。说明采用的换日口径，记录接近子夜的情况。
- **流时。** 综合流日所见，再查时支填宫。月位起时从月亮宫起酉，沿地支逆数至所问时。日位起时从日支宫起卯，沿地支顺数至所问时。只有给出明确钟表时刻和地点口径时才细化。所问日期或时辰缺失时，保留在现有层次。

## 倒限和高风险主题

先回查原局关键破绽，再寻找相应宫度限和大限中长段连续失助、旺衰骤转，最后核顶星、太岁、原流重复及是否尚有制化。论一星克限或余奴犯限时同时查救应。对现实当事人将倒限表述为高压力或多重受制结构，医疗、事故、生死等结论以现实证据为准。
