# 专题取象

先读原局，再追踪专题所需的宫、曜、宿和限年。以可核对的盘面条件限定取象。

## 转太极与父母

- 先完成命主自己的尽三、三度和喜忌，再决定问的是「六亲对命主有什么作用」还是「这位六亲本身如何」。前一问用命元，后一问为相关人事另立一个明确太极。转换后重新计算那一方的生克，保持其他星的原本性质。
- 以太阳为父、太阴为母，分别以其落宿的属曜立太极，再查日月本宫、对宫和三合。新主体按所取属曜论生克，其他星照原曜处理。日月本身为取法时按光明、晦蔽等本性讨论。父母的宫、田宅及命主十神中的财父印母可作并证。
- 三度上可用的星能作用于新太极。论父母的新太极且该度无星时，可补查该度属曜的性质。这条补读服务于该太极，原局尽三的空宫仍按原来的规则读。
- 用神从尽三选出，三度能扶伤或改变原来的成败程度。穿度一喜一忌时各写各的作用。流年回到原局与限的数据，论流年如何发动原局，再看对这位六亲的额外影响。

## 感情、婚姻与相处

1. 先定命、用与气数，读夫妻宫、所守星与宫主、男女宫、月身，以及尽三实际遇到的配偶有关之曜。传统男命以财、女命以官杀作一条线，日月命以宫曜和光明等象为主。夫妻主、宫内星和十神候选可并证。尽三中起主要作用且与配偶主题吻合的星优先。全盘核心是官杀生印、财养用神等关系时，按那条真实关系选星。有原局清楚的喜应才加用正曜优先等细则。
2. 分开看是否相感、是否能互助、是否有条件维持。正余曜同时感应、比劫争财或伤官克官，可作为竞争、分离倾向的一条传统线索。须再看相关曜有无制护、宫星指向与双方现实处境。还有支持和冲突两类证据时，照样给出两者。
3. 判断原局总体后，已有具体对象才细化生肖或月亮带入。问单身者未来感情，以原局关系基线配限年引动为主。运势重点看夫妻／男女宫、相关配偶之曜，及它们是否同时被顶、吊、填冲。妻夫象可由多颗星并证，一颗星兼具财、宫主或限上曜等身份时，写出本次使用的依据。
4. 月命尤其要看月相、昼夜、季节及光辉。土计会晦，火日可助明，气可散云，水既可能清辉也可能冷、与土成云。金、木等作用依组合先后。日命围绕太阳是否明、宫星关系和时运，避免把普通五行命的固定配偶十神强加给日月。
5. 同年有喜曜进入可表示相感，同时有限上星受克可呈现相处成本。已有伴侣、刚认识、长期分居等现实阶段会改变同一象意的具体表现。若问题涉及关系网络或出离取象，可核兄弟宫、奴仆宫、月身与余曜是否共同指向该主题。性取向、信仰或当事人的关系事实以当事人陈述为准。

候选配偶曜都进入尽三时，比较哪一曜实际联系夫妻宫或男女宫、穿三度、与对象生肖相应，以及是否在相识时被限流引动。双方共用一曜时先明确该曜代表谁，再给另一方另找有实据的主体。正曜与余曜各查本身的作用，不因名字相邻就视为同一角色。

## 多线配置、水火相济

- 两气成象先核双方的季令、状态与实际出场次序。未申旺火遇水，水可兼具润燥的气数。在尽三确实先遇水而能济火的前提下，水可由克我之杀转为有用之官。随后识别哪颗星真正破局，常见一支是土计阻水，另一支是过量火罗助燥或伤护水之金。
- 护局可由木气制土、金泄土或其他实际在场的星完成，前后、远近、犯不犯尽决定力量。写清「需要这两气成象 → 谁破它 → 谁护它」，第二层再说明该曜掌哪宫、可能指向哪件事。
- 水火相济与水火交战可出现在不同层面。原局可能借水润火，某限若火为限上星而流孛来克，仍有局部冲突，须看原局、限与流三者。按实际涉及的人事宫限定主题，包括疾厄相貌、事业或感情。

## 倒限、送养、罗计轮回

- **倒限**用于回看盘面的严重险象。核查原局最忌处与身命可支撑处，再找它被大限宫、度引发、限度或限上曜受冲击、顶曜或太岁又填冲同一关系的交集。相同的线路如果尚有用曜得护或流年补助，应同时写出。跨限、宫宿交界、经过罗计、原流同一忌曜的落点可作加重条件，单条只够提示需检视。这些组合用于辨析传统盘象。寿命、疾病及自伤风险以现实资料与专业评估为准。
- **送养、迁出**以实际身世为问题背景。查父母与田宅、兄弟和迁移，看亲缘、居住与扶助是否分属两线。必要时并查胎宫、月身及命元所躔宿度为何把两类星连在一起。亲缘宫关系、迁移线和外来扶持互有呼应时，可讨论亲缘与实际照料分属两线的象意。
- **罗计轮回**用来比较关系或事件反复的区间。先有原局主题与限年引发，再检查本命罗计、流年罗计是否在同一对宫并合，或当事人生肖及相关年支是否又应该轴线。各轴参考值为子午 9、丑未 8、寅申 7、卯酉 6、辰戌 5、巳亥 6。按这些数值比较区间，并核已知起点及后续限年。吉凶仍由原局和限流给出。罗计对宫分半、喜曜和月身／命同在一半的「拦截」另用于看该曜是否易为身命所用，计算时按实际轴线分割，边界曜需标出。

## 财运、家产与职业

- 财要同时查五行财曜、财帛、田宅和财库。库位按财本身的五行，木未、火戌、金丑、水土辰。比如火命克金，金财库在丑。财宫仍取该盘实际财帛宫及宫主。守曜与宫主互入财田、喜财伴身等加证依各自落点核实。
- 先看身命能否承财、尽三是否真的成于财或得用，再看气数是否护财、库与田宅是否相助。宽义「财气通门户」是财曜有用而得护，狭义是喜财入命。财为忌要说明如何有制，财好却用神被伤宜分别述。普通财运重看何限何年扶引已有财田关系。继承另核田宅、父母、兄弟和现实产权，单一田宅吉曜不足以直接断继承。
- 职业先看大类与工作环境。官福关系、官印或财官、日月、用神是否纯，支持组织内责任或管理。食伤财与助力多见经营取象。印官常用于规则明确的岗位。食伤或偏曜突出可支持技能、创作或专业取象。木火可并文教，金水可并商业财务，水亦可并流通，火土可并组织行政。迁移常和差旅物流、奴仆和服务协作、疾病和医疗服务、官禄与岗位职责相关。给组合与可能工作形态，细行业与职级须现实资料参与。
- 工作年运先看顶曜和限是否共同指向官、迁移或用神。区分岗位变化、升降或行业重心。暗拱取三合两端夹拱中神（如申与辰拱子）。用于四柱时还要求年月两柱或日时两柱相邻构成。
- 查财田互垣时，核财帛主入田宅、田宅主入财帛两个方向。官福互入同样核官禄主入福德、福德主入官禄。单向落点照普通宫主飞入取象。分别看入宫的星有无得令、受护并作用于原局。
- 若要核武职的象，同时看火金或金水的成用条件、戌库是否被盘面引动。工作年运出现迁移曜与官禄曜时，分别查环境、地点和具体岗位职责是否发生变化。

## 学业、财库与职务升调

**学业。** 先核学龄所行宫度限、命身承受与福德、官禄是否得用，再查喜用曜所守、所掌的宫与学习、文书和迁移主题是否有实际联系。可用这些证据区分学习条件、求学变动、技能专长与考试机会。学龄阶段还可查家庭能提供的支持。

**日月命财库。** 财库从财帛宫的主曜五行起。例若财帛在寅，宫主属木，木库在未。需要旁查食伤库时，可从相貌宫的主曜五行起，如申取水，水库在辰。再按库宫的实际星曜和限流引动取象。

**职务升调。** 先核身命承受、官禄与福德的实际宫星，以及尽三所定的用曜。按所问年的太岁填吊、宫限和度限复核原局，再查流年化曜中承载催官与天马的星是否一并被引动。若变动信号落实，而官用并未得助，可先取平调、职责更替之象。若恩曜护官、煞有制化且限度支持，再考虑升任之象。有具体日期需要比较时，以月限和月将筛出同象月份，再查流月填出及该日太阴是否会到已经取定的恩曜、官曜。单个名目用于辅证。

## 疾病象与胎宫

- 胎宫取节气月支，沿地支向前加三位，不把月支自身计为第一步。辰月依巳、午、未取未，未月取戌。核胎宫守曜、主星和命元是否有实际关系，再读身命、相貌、疾厄、福德，避免把地支宫和人事宫混叫。
- 分别检查身命太弱、童限财杀压力、用神掌疾或入疾，以及命身与用神同时受伤。对日月尤其审土计晦蔽与有无助辉，火金受晦亦按其本性看。用神与疾厄有关不等同用神应去，能否扶救与取何种主题是两个问题。
- 五行可作部位类比，包括木肝胆／筋、火心血、土脾胃、金肺与皮毛、水肾水液。须结合所在宫、参与星、主要失衡与时间层。地支经验表可作象意并证。这些对应属于传统分类，具体疾病、生育状况及治疗由医学检查确定。
- 传统地支部位旁参可按子下腹、丑腹、寅上肢、卯目手、辰胸背、巳面齿、午心腹、未脾胸、申呼吸、酉肝腹、戌背肺、亥头肝核象。先确认有相关的命身、用曜、疾厄或相貌宫证据。

## 官非、工作冲突与名誉

- 找现实问题最贴近的原局关系。财坏印可涉及账务或信用，官印受损可指组织规章，迁移涉外出事务，兄弟或奴仆可并同伴，男女宫可指娱乐场景或人情牵扯。须以有关实际事实限定取象。
- 重点检查官禄宫的守曜与宫主，特别是该曜压住一条关键用神，或虽未进尽三却独守中天且被四柱或时运重复引动的情况。太岁引动官禄曜，且该曜又克度限并伤主链时，可把该项作为从原局追踪到当年的重点。
- 给出具体可核对的「事业宫／宫主 → 冲突星 → 被引动之限或用」，并列有无化解与直接证据。法律事项可写成规则、合同、工作或人际摩擦的关注点，责任和结果以文书与专业意见确定。

## 子女与子女太极

1. 先看男女宫的守曜、宫主、原局所喜所忌及与之相关的尽三、穿度。传统女命再看食伤、男命看官杀，也可用时柱辅证。空宫沿宫主追索。男女宫主刚好是命主且其余无特殊联系时，以通常关系读。传统一些口诀用正偏、长生与男女作类比。盘面输出聚焦相处、照料、分离、才能等可讨论主题。
2. 分开答「子女之事给命主带来什么」和「子女本身如何」。前者保持原命主太极。后者选有依据的子女星，重起自身的生克，并查三方四正。同一星在两套关系中的喜忌可以不同。另看身月与迁移等宫是否提示物理距离与相处机会。
3. 对食伤配印和枭神夺食，使用尽三先后和保护链。比如食伤先成关键，后出的印直接伤它而无护，才读夺食。若印所做的是制化先前的杀、并使结构协调，则是配印。三度伤到保护链的关键曜时，追溯它为何使子女主题受牵连。拒绝只凭一对星相克就定全部家事。
4. 按子女星自身的五行起长生。例如取金为子女曜，按巳起长生，顺推午沐浴、未冠带。核该子女曜是否实际得用、得地和受护。性别、数量、健康与有无生育的确认，遵从实际资料和医学评估。
