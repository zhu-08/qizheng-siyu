# 基础技法与星命

先用 [本命主流程](reading.md) 建立命元与证据，再用本页细化。所有象意须经过盘面条件核对。

## 五行力量和命景

- **五行有季候。** 寅卯木旺、巳午火旺、申酉金旺、亥子水旺。辰未戌丑土当令，同时分别保有木、火、金、水的前季余气。可依节气深化寒暖判断，如寅卯春雨偏寒，辰月转暖。早晚与实际月相纳入日月命的光明判断。月令、恒星太阳宫、月相各取自己的量。
- **月令给强弱背景。** 庙垣和升殿显示星得地，入垣、得令、升殿合看，并用受助、受克和见曜先后修正。星体的居宫、居度和行态都可影响有力程度。先看承受力，再问尽三有没有用。
- **五行关系有条件。** 土能培木，也能埋金、浊水或晦光。水可润木、淘金，也可漂木、令火失光。火可以调候、炼金，也可燥土、熔金。金可斲材、削伐活木或泄土。木能疏土、泄水或延火。先确定命元及物象，再问比例、季节、先后与组合。见第三星时检查它究竟护谁、泄谁和改动哪一环。
- **气数与生克并审。** 辰至酉多需水润，戌至卯多需火暖，孛和罗也可参与调候，力量及过量另算。暖局的星同时可以助杀，润局的星也可能伤印。可把同一星的利处与代价都说清。
- **先用再回命。** 体是当前太极，用取能成全该太极或化其关键矛盾者。先从尽三确证能用的链条，再看该用落何宫、掌何宫以及承受力。宫与度同见是重复证据。宫度矛盾时逐项讲强弱和环节。中天（官禄宫）和命库可作为补证。库位随所论五行的墓库判定。原始盘面或取库法未明时注明依据。

## 分命元取用

| 命元 | 先问本性 | 季候和组合核查 |
| --- | --- | --- |
| 木 | 生发、根基、抽枝、开花或成材 | 春木可培、润、暖，核实活木受金损伤。夏木重润，火适量可成花，太过转燥。秋木先分活木与可斲之木，早见培根与适合修剪会改变金的作用。冬木查冻、藏、复苏。气可能助木，也可能争根财。 |
| 火 | 发热发光并持续 | 春木能助火，夏火查水火是否相济，秋冬查燃料及火是否弱到承受不了水。木多也可能火炽，金可交明或坏印，水可调火也可成杀。罗能暖或犯火，辨本曜与余曜。 |
| 土 | 承载、养育、厚薄、湿燥 | 春土虚可喜火温扶。夏土先辨有没有润，再看火印木官的次序。秋土能容木或让金得用，考量土厚度。冬土怕寒冻，水、木、金的顺序和有无暖气会改变结果。核实培木、泄土、土燥与水漫的条件。 |
| 月 | 夜间光明、清润、圆缺 | 可取木气清辉、金星伴月、火月同明。临望的夜月另查争光，土计优先查晦月。寅卯见水孛先问寒雨，辰月及炎夏问润。若无准确月相，用生时与盘面可靠条件表述。 |
| 日 | 光明、温度、辅助、可见性 | 昼日有辅，寒时可借火暖，暑时水可润，一土可为云、土计并有晦光之象。火与罗在强弱、早晚不同的日命上分别辨同明和争光，金水也会随寒湿从辅阳转为遮蔽。夜日、居宫与躔度的阴阳均须提及。 |
| 金 | 成器、清润、光泽 | 春金体虚查土生及暖，夏金火炼同时查水济并防火熔。秋金已成，重点查晦埋、过炼与如何显露。冬金查寒水、厚土和暖气。土既可能藏护金器，也可能闷埋失色，要结合见水与先后。 |
| 水 | 流动、清浊、能否成渠 | 春虚与秋清都要核土是成岸还是混浊。夏见适量火可相济，冬水查冰寒与解冻。木可导水显秀，金伤木可能破坏泄路，孛加水要看河道能承多少。 |

日月取自然光景和宫星组合。以月作身点与以月作命元是两种用途。女命仍走完整的命、命元、身三度。对双胞胎，先读共用本命结构，再分别立太极。异性按男女命元规则各取，同性以有余奴的正曜与余奴分长幼。金日月无对应余奴时按兄弟宫的主星和可用分法展开，记录假设后各自复核三方、身命及行限。

## 十神、先后与制化

生克十神从当下太极的五行关系起。照着具体顺序记录比劫、印、食伤、财、官杀。生年化曜另有固定表，可作为查星依据。

| 结构 | 核验方法 |
| --- | --- |
| 印化杀／食伤制杀 | 杀先克体，再问印能否化杀护体，或食伤能否制杀。财可破印党杀，枭可夺食令制杀失力。 |
| 官印／财生官 | 官是否得用，印是否承接，有无伤官克官。财生官对有承受力的结构可助，杀重体弱时可能党杀。 |
| 食伤泄秀／食伤生财 | 身有余力、食伤可用且财能接。遇印制食或劫夺财再看途径是否有护。印、食配合也可各发挥作用。 |
| 财坏印／财去过印 | 先确认印是否成局所需。有用印受财制时找比劫克财护印，印重而滞时财有裁抑之功。若劫为余奴，再查犯主和过量。 |
| 比劫夺财／食伤泄劫／官杀制劫 | 确认有财可争。食伤能疏泄比劫并生财，或官杀受用时制劫。命弱而财重时，比劫亦可成为实际支援。 |
| 羊刃驾杀／杀枭或官枭 | 核明旺衰、刃是否受制、杀枭是否把压力引走，以及杂煞有无加重。同名组合在不同命局可成可败。 |

以生克之外的气数验证。先印后财与先财后印可产生不同局势。同一步骤的星仍可能互动。每条证据链读到三节点，优先跟进最直接的护喜、制忌、伤喜、生忌路线。第二个喜与第一个喜可以有冲突。结论可以写成有得有失，指出哪处支撑仍在。

## 星性、宫象与神煞

- 日月可用于父母、光明与身命。金常取清丽、修饰、金水秀。木取生发、仁与清气。火取光、热、礼。土取承载、慢、厚或阻。水取智、流动和变化。四余按木炁、火罗、土计、水孛追查同类和偏性，亦可取风、热、云晦、雨湿。落宫和前后生克决定具体取象。
- 逐一看所守和所掌。命与相貌关本人和表现。财帛查可动用的财，田宅查家与资产。兄弟与奴仆可取同辈、朋友和协力关系。夫妻与男女可分别取伴侣、亲密和子女。疾厄、迁移对应困难与外出变化，官禄与福德看职责、资源和精神受用。按问事选择三方、宫主和关系链。
- 刑冲合害、三合、阴阳、地支宫是盘面结构的语言。太岁填冲和尽三都用三方四正查星，再分别按相应规则读。两星各照目标宫时，额外核实它们彼此是否同宫、对宫或同属一组三合。
- 神煞用于加减与定位之象。重点看天乙贵人扶助、空亡之虚实、阳刃之刚险、禄、驿马之动、咸池桃花、华盖孤清、将星职权、学堂文昌、天德月德、孤寡、墓库和长生十二态。星盘的天乙取出生年干查宫。并参四柱神煞时，分别核对所用的年、月、日、时。落实到哪颗星、哪个宫限、是否制化、何时被填。无神煞表时先依据宫星和运势完成主解，再将需核的神煞列为待查。
