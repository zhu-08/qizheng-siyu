# 宫度权重与组合核查

## 宫与度怎样加减

- **三度的轻重。** 依命度、命元主星所躔度、身度逐项查同曜四宿。比较冲突证据时，常以身度最重、命度次之、命元主星所在度再次，因为身为归结。尽三第三步也侧重结果。若命宫、命元星所在宫、月亮所在宫有重合，可从两个角色复读同一组合，并注明它们共用原盘证据。
- **宫度成败。** 尽三得用而三度护用，主线相互支持。尽三受阻而三度有救，可得原局未能充分兑现的助力。尽三先成而三度伤用，多取成中有损、过程起落。尽三和三度均受制时，找尚能护身或调候的力量。用神完全不明、相犯后主链为空时，直接观察三度中何曜能护或伤命元。
- **细化有先后。** 起手先看命元主星在何宫何宿、得令与否。入垣、升殿、得令只占一项也可先视作有根基，三项俱得、俱失再作旺弱两端。尽三优先核当前三方四正，进入一条主线后，再精查承担关键作用之曜的宫、度与行态。前两曜贴近时保留共同作用，同时说明先后对成局是否顺畅的影响。
- **层次和具体主题。** 先判断用神能否成立、有没有护住，再以所守和所掌之宫定主题。财田官福得到主力之曜较能落实到家产、资源或事业。疾厄、兄弟等得用时也有益处，去向依相应宫义。命元兼任所问宫主而本宫空时，可查其余曜及三方是否感应此宫，随后回到有无制化。取用并不抹去其它显著交战，例如两颗喜曜相克仍可在其对应事务中出现冲突。

## 夹照、互垣与主曜照临

- **守、正照、拱照。** 同宫为守，对宫为正照，同组三合为拱照。论度另查所躔之宿与同曜四宿。择日或方位问题中的到山、到向、到座先落实所用方位口径，再查相关照临。
- **日月夹。** 核对太阳、所夹星、太阴的实际排列。三者同宫时按该宫中的角度顺序查居中者。论宿度时三者须在同一个宿，角木与斗木这类同曜异宿可记为四度相通。日月在两侧相邻宫可记弱证。同宫或同宿确实夹到喜曜或忌曜时，分别看其作用怎样加强。
- **互垣与宫位交叉。** 财帛联查田宅与福德，并查身命、日月、福禄之曜是否守照。具体互入条件见 [财运、家产与职业](topics.md#财运家产与职业)。官禄和福德空宫时，再查宫主及对宫三方有无可用星。读相貌或心性时，命宫和相貌宫均有星可分别核先入之曜，再看相照组合。
- **中天及八杀朝天。** 官禄宫是中天，其守曜可加强所主议题，仍需看星与命、用的关系。八杀朝天从卯火立命的静盘理解，申水居疾厄而克火，重点在杀能否制化为权。落在实际盘上须先查杀与命、制化与官禄响应。
- **午未并参。** 四柱旁参可按所用支合口径核对。七政盘取午日、未月，午未相感时保留日、月各自的光明、昼夜和作用。生肖六冲也须回看生肖所代表的星和宫是扶喜还是伤用。

## 余奴与杀的先后

正余相犯先查两星之间实有同宫、对宫或共属一组三合。论度时只比同曜四宿。第三曜同在相犯位置或同曜宿群时，查它如何生扶、牵制其中一方，保留犯而未尽的作用。日月在其中也具此作用。犯尽时主链可略过该对星，后续仍可据落宫取环境、欲求或所得较难留住的象意。

当余曜与命元本曜同类时，先定所见次序。先见余曜侵占命元，再见能制余的杀，可取杀制余。先见杀克命，再遇余曜参与抗杀，可给其护命之功，同时保留它的争夺或分担。以木为例，先炁后金时核金能否制炁，先金后炁时核炁能否承接金的作用。春木先被金伤根和秋木可由金成材的条件仍要分别判断。度限遇其余曜时另读犯限，与本命喜忌并陈。

## 十神名称与作用分开核

围绕当前五行命元，先辨是哪类生克关系，再看其作用。克我有节制、可用时可取官，压倒命元时取杀。我生能适度泄秀时可取食神，泄伤命元或破坏用官时可取伤官。生我能扶助时可取印，过量夺食或助忌时查枭的作用。财星可按正曜、余曜分别取正财、偏财，例如木命以土计同属财类，土取正、计可取偏。日月为命元时按阴阳光明取象。

- **身财两停、食伤制杀。** 身财强弱相称时，若另有比劫扶身而不夺财，可见协作承财。食伤能有效制杀才谈成用，先见食伤和先受杀克再获救应分开。制力太弱则杀患仍在，制得过头则原有的可用压力也会减弱。
- **比劫护印与喜曜交战。** 先确证财确实伤印、且比劫能制财护印，再审命元是否另受余曜之犯。用来护印的星和另一个喜曜仍可对撞。追查宫与度是护住同一个目标，还是只护住其中一环。若护印之星被限年引动，已经形成的其它交战也可能随它显现。以两曜的所守所掌和流年落点区分两条人事线。

## 依星曜本性和季候细化

| 检查项 | 可复核的条件 |
| --- | --- |
| 日月得位与反背 | 日喜寅卯午等阳明处，居酉、亥、子丑或月度时查失位与有无辅曜。月喜未归垣、酉得位和月度，居午卯、日度或土度时查失位或晦蔽，并看宫宿抵消条件。月在寅可有清辉，月在戌可按平位。日居酉而月居卯、日居子而月居午，是反背的典型组合。行限中日命走月度可审反背，月命走日度可审借光。 |
| 日月光明与月相 | 先看盘面月相、照明比例和昼夜。寅卯夜月通常喜火暖、金伴和木清，同时查水孛寒雨与土计晦光。辰月水孛有润的可能。近望的夜月很明，火罗同见要另判助明或争光。日月同见时也看前后、谁遮谁与照临所用。 |
| 行态与昼夜 | 顺、逆、伏、留放在得令、得地、喜忌之后。金得用时伏或留仍可能有力，急逆时更需留意，若又为忌且伤到关键用曜可加重冲突。水迟留可减其效。昼盘日主明，木炁、土计、水孛可多一层昼间作用。夜盘月主明，火罗、金可多一层夜间作用。 |
| 火金同明与偏枯 | 夜生火命得金，可查同明之用。日命遇火还查争光。火逢土计，即使土为有用的食伤，也可同时遮光。把两条作用分别列出。暑段若火土已盛、水孛又被制，日可能进一步加燥。寒段若火罗日均不通，查是否未能暖局。 |
| 木南奔与成材 | 夏木本虚、处火宫或火度又反复见火罗时，核有没有水济。火旺且无水才加重焚象。秋木受金时先判断根基及土培，适合收成之木可因金修斲成材。正在培根的活木会因过度斲伐受伤。 |
| 罗计拦截 | 以罗计的实际对径划分两半，核哪一半留有身月、命元或问事所用之曜。少星一侧只剩一至两曜时，隔绝之象较可取。多个曜杂处先回主链，轴上之曜另注明。 |

季候以节气定位。需要补五行相对力量时，可将令曜记为旺，令曜所生为相，生令曜为休，克令曜为囚，令曜所克为弱。辰未戌丑以土当令，同时检查上季余气。这个序列用于估重，仍需回到实际寒暖、星曜承受力与组合。
